## Development Workflow

### Step 1: Research & Snap
- Map roads using Google Maps Snapping.
- Retrieve billboard anchors and orientations.

### Step 2: Math & Polygon
- Graph out the visual cone polygon.
- Calculate distance and vehicular heading alignments.

### Step 3: Integrate
- Receive GPS trajectories from the external GPS agent.
- Calculate view counts and export reports.

### Step 4: Visual Dashboard
- Render animations showing vehicles flowing through visibility fields.

## Candidate MVP Features

* **Candidate A: Visual Cone Raycaster**
  * Spits out 2D visual polygons accounting for billboard angles.
* **Candidate B: Lane Direction snapping**
  * Filters out vehicles moving in the wrong direction relative to the billboard face.
* **Candidate C: Pedestrian Sidewalk zone**
  * Enables omnidirectional viewing triggers for slow-moving trajectories.

---

## Evaluation Framework

Every feature must be scored on:
- **Visual Demo Potential (1-10):** Can it be visually demonstrated on a map/canvas instantly?
- **Mathematical Integrity (1-10):** Does it model real physics (angle decay, distance attenuation)?
- **Integration Feasibility (1-10):** How easily can the external GPS agent connect and submit logs?
